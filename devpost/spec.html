Technical Blueprint

User Story & Acceptance Criteria Assistant

A lightweight agile-assistant that converts rough business requests into backlog-ready user stories, Gherkin-style acceptance criteria, and a clear dependency/open-question list.

Local MVP Gemini-powered Single-screen workflow

Architecture

Core Journey

1
User enters a raw business request
Usually a vague idea or informal requirement.
2
App validates and frames the request
Optional role selection and guardrails for empty input.
3
Gemini builds the agile artifact
User story, Gherkin, dependencies, and open questions.
4
User reviews and copies the output
Result stays on one screen and is easy to share.

Component Highlights

Input and Role Framing

Collects the raw request and optional role, then passes it into the main pipeline.

Generation Orchestrator

Validates input, builds the prompt, and calls Gemini with clear instructions for a structured result.

Result Renderer

Formats the output as Markdown so it is easy to read, review, and copy into backlog tools.

Error Handling

Keeps the request visible and shows a clear, human-readable failure message when the model or API fails.
